# Documentation Archive

This directory preserves release-specific evidence that is no longer current.
Archived files are excluded from the published documentation site and must not
be used as the current API, roadmap, or release procedure.

Current user documentation starts at `../public/index.md`. Current maintainer
procedures live under `../internal/`.

- `releases/` preserves version-specific criteria, notes, and audit evidence.
- `implementation/` preserves completed execution logs that are too detailed
  for current architecture, guides, or backlogs.
