CHAPTER 09 · WEB FONTS

Web 字体：把字体送上网络

网页要用一款访客电脑里没有的字体，就得把字体文件下载下来。这带来三个新问题：怎么声明、文件多大、下载期间显示什么。这一章讲清 @font-face、WOFF2 压缩、子集化，以及那个让你纠结的 font-display。

第一步：用 @font-face 声明一款字体

@font-face 把一个「字体名字」绑定到一个「字体文件 URL」。之后在 CSS 里像用本地字体一样用它。浏览器在真正需要时才去下载。

@font-face {
  font-family: "MyFont";              /* 你起的名字 */
  src: url("myfont.woff2") format("woff2"),  /* 首选，最小 */
       url("myfont.woff")  format("woff");   /* 旧浏览器回退 */
  font-weight: 400;
  font-display: swap;                 /* 下载期间的策略，见下 */
  unicode-range: U+0000-00FF;         /* 只在用到这些字时才下载 */
}

h1 { font-family: "MyFont", system-ui, sans-serif; }

第二步：文件格式与体积 —— WOFF2 几乎是唯一选择

同一份字体，不同封装格式体积差很多。WOFF2 用 Brotli 压缩，是目前最小、支持最广的 Web 字体格式。

format.size

同一款字体的相对体积（示意）。WOFF2 ≈ 原始 TTF 的 40%，对首屏加载速度影响很大。

第三步：下载期间显示什么？font-display

Web 字体要下载，期间这段文字怎么办？font-display 决定这段「空窗期」的行为。拖动下面的时间轴，看三种策略的差别。

font-display.timeline
下载进度 0.0s

font-display空窗期（字体没下完）体验特点
block / FOIT文字不可见（留白）等字体；超时才用回退。慢网下用户看到空白
swap / FOUT立刻用回退字体显示内容秒出，字体到了再换 → 会「跳一下」
optional用回退；本次几乎不换最稳，不闪烁；首次访问可能就用回退字体
FOUT vs FOIT
FOIT（Flash of Invisible Text）：先空白，字体到了才显示——内容出现慢。
FOUT（Flash of Unstyled Text）：先用系统字体显示，字体到了再替换——会闪一下但内容不延迟。
现代最佳实践通常是 font-display: swap（要内容优先）或 optional（要稳定无闪）。

第四步：子集化与 unicode-range —— 别下载用不到的字

一款中文字体动辄几 MB（上万字形）。但一个页面可能只用到几百个汉字。子集化（subsetting）把字体裁剪到只剩用到的字形；unicode-range 则让浏览器按需下载对应分片。

subset.size
字体里的字形（绿=页面用到，灰=没用到）
字形数：8000
文件大小：4.8 MB
下载时间(4G)：~3.5s

完整中文字体包含上万字形，绝大多数页面用不到。

CJK 的特殊难处
英文子集很简单（就一百多个字符）。但中文/日文/韩文有上万字形，且页面用到哪些字往往事先不知道（用户生成内容）。常见做法：按 unicode-range 切成几十~上百个分片，浏览器只下载页面实际命中的分片（Google Fonts 的中文就是这么做的），或用工具按已知文案做精确子集。
检查一下理解 ✅

问：想要「内容立刻出现、字体到了再换」，font-display 该用哪个？会带来什么副作用？

看答案

用 font-display: swap（即 FOUT）。文字立刻用回退字体显示，Web 字体下载完成后替换。副作用是会「闪一下 / 跳一下」——回退字体和目标字体宽度不同会引起回流。想完全避免闪烁可用 optional，代价是首次访问可能一直用回退字体。
