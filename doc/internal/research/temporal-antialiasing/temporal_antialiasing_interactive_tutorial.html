互动教学 · TAA 时序抗锯齿

TAA：把过去几帧的信息偷来，给这一帧抗锯齿

MSAA 4× 对静态几何有效，但对着色噪声（specular highlight、alpha test 叶子、体积雾）束手无策。TAA (Temporal Anti-Aliasing) 换个思路：每一帧用不同的 sub-pixel 偏移采样一次，再把上一帧的结果通过 motion vector 重投影过来混合。均值 = 4~8× 超采样效果，成本却只有 1× 渲染 + 一次拷贝。代价是：ghosting、闪烁、需要合理的 clip/clamp 策略。

1. 亚像素 jitter每帧用不同 sub-pixel 采样点，逐帧累积等价于超采样。
2. Reprojection用 motion vector 找出这一帧像素在上一帧的位置，从 history buffer 取。

01 · 走样 & MSAA 的局限

不是所有 aliasing 都是"边缘锯齿"

走样有两类：几何走样（边缘锯齿，MSAA 能处理）和 着色走样（specular sparkle、shader normals、alpha-test dithering，MSAA 不能 处理，因为 MSAA 只在几何边缘 supersample，内部只 shading 一次）。TAA 通过每帧 sub-pixel jitter，跨帧平均，等价于 shading 也 supersample。

左：细线 rasterize；中：specular 亮斑；右：alpha-tested 叶子。MSAA 修好左边，中/右几乎无效；TAA 三样全修。

TAA 核心公式
C_out = α · C_current + (1−α) · C_history_reproj α 通常 0.05~0.15（1/16 ~ 1/8） 等价加权移动平均 → 累积样本数 N ≈ 1/α

α=0.1 → 稳态相当于把最近 10 帧的 sub-pixel 采样加权平均一次。10 帧 × 每帧不同 sub-pixel = 10 sample 超采样。

MSAA 为什么救不了 specular：MSAA 存 4 个 coverage + 只 1 次 shading。specular = (N·H)^power，power=32~256 时高光点小于像素，coverage 全 1 但颜色只算一次 → 该像素闪一下，下一帧不闪。
02 · Halton 2/3 jitter 序列

用什么规则每帧偏移一点点？

不能用 rand()——低差异（low-discrepancy）序列才能保证 N 帧后 sub-pixel 均匀覆盖。工业标准是 Halton(2,3) 或 Halton(2,3) reordered。序列在 [0,1)² 里，减 0.5 后作为像素级偏移传入投影矩阵。

在一个像素 (1×1) 里画 N 个采样点。Halton 均匀分布无聚簇；伪随机常出现聚集空洞；均匀网格看似完美但和场景网格对齐时又暴露 aliasing。

Halton radical-inverse
halton(i, base): f = 1, r = 0 while i > 0: f /= base r += f · (i mod base) i //= base return r jitterX = halton(i, 2) − 0.5 jitterY = halton(i, 3) − 0.5
投影矩阵注入 jitter 
// After building projection matrix each frame:
proj[2][0] += 2.0 * jitterX / screenWidth;   // subpixel offset
proj[2][1] += 2.0 * jitterY / screenHeight;
// Important: motion vector 计算必须用 unjittered proj，
// 否则 jitter 会混入 motion 里污染 reprojection。
03 · Reprojection & motion vector

找出这一帧像素在上一帧的哪里

物体动了、相机动了，像素不能只从"同一 uv 位置"读 history——那样静止的车、跑动的角色 history 会错位。方案：G-buffer 里额外写一张 motion vector：每像素记录"从上一帧到这一帧的屏幕位移"。reproject uv = current_uv − motion_vec。

红点是当前帧位置，蓝点是 history 里同一物体的位置。橙色箭头是 motion vector。取 history 时用蓝点位置采样。

motion vector 计算
pos_world = reconstruct from depth + inv(VP_current) pos_prev = VP_prev · pos_world uv_prev = pos_prev.xy / pos_prev.w · 0.5 + 0.5 motion = uv_curr − uv_prev

静态几何用逆投影 + 上一帧 VP 矩阵反算；动态物体（骨骼动画/粒子）在 vertex shader 里主动写 prev_position 到 G-buffer。

取样用 bilinear 而非 nearest：reproject uv 不整数对齐，双线性能减少 stepped edges。但双线性也会引入模糊——TAA sharpen 就是补这个。
04 · Ghosting 现象

动物体后面拖出淡淡的残影

Ghosting = history 里的信息被错误"续存"到当前帧。原因：motion vector 不准、或 history 里的物体已经不在那了却仍被高权重混入。典型场景：透明物体没写 motion（motion=0，但视觉上它在动）、快速转向、shading 剧变。

白球在蓝背景上左右移动。history 权重越高，稳定性越好但拖尾越明显。启用 neighborhood clip 后立刻消除拖尾——因为背景像素的 history 值（白色）落在了当前 3×3 邻域的色彩包围盒外。

Ghosting 常见根源

  • 透明物体没有正确的 motion vector（velocity buffer 里是背景的 velocity）。
  • 粒子系统：alpha-blended 粒子没写 motion，跟着背景 velocity 走 → 拖尾。
  • 阴影／反射变化：几何位置没动，但 shading 颜色跳变——history 里的旧颜色仍在。
  • 相机快速旋转：motion vector 里像素跑到屏幕外 (disocclusion) 却没被检测。
05 · Neighborhood clip / clamp

用当前帧邻域颜色范围"净化"history

Salvi & Vaidyanathan 提出的经典技巧：取当前帧 3×3 邻域的颜色 min/max（或均值 ± 方差），构成 AABB。history 颜色不在这个 AABB 内 → 说明是过期信息，clip 或 clamp 回 box 边界，防止污染。业界最常用 YCoCg 空间做 clip，比 RGB 空间 luma 敏感度更好。

2D 色彩空间可视化。current pixel（红点）在中心 3×3 邻域构成的 AABB 里。history（蓝点）在外——naive 直接混合污染；clamp 拉到最近角；clip 沿 current→history 线剪到 AABB 边界（更 aggressive，保留更多锐利）。

YCoCg → RGB
Y = R/4 + G/2 + B/4 Co = R/2 − B/2 Cg = −R/4 + G/2 − B/4 逆变换： R = Y + Co − Cg G = Y + Cg B = Y − Co − Cg

RGB 三通道相关性高（灰色像素三个都变），YCoCg 把亮度和色度分离，AABB 更贴合。工业实践几乎全用 YCoCg clip。

06 · Disocclusion 处理

"上一帧被挡住、这一帧露出"的像素

相机绕角走一步，之前被墙挡住的那片草坪突然出现在屏幕上——history 里那个位置存的是墙的颜色，直接用会立刻 ghost 出一大块墙纹理。检测方法：reproject uv 越界，或 reproject 后的 depth 与当前 depth 差异大。

前面的红柱挡住了后面的草。相机右移后，柱子左边露出草地。高亮区域就是 disocclusion mask——这里必须完全用 current 帧、不能用 history。

3 种检测

  • UV 越界：reproject uv < 0 或 > 1 → history 里没这像素，权重设 0。
  • Depth 不一致：|depth_curr − depth_history_at_reproj_uv| > ε → 前后是不同物体。
  • Normal 不一致：|normal_curr − normal_history| 大 → shading 会不同，降权重。

detected 后：不用 history / 增大 α（用更多 current）/ 或从邻域插值补一个 history。

07 · Sharpen 后处理

TAA 天然模糊，最后来一刀锐化

TAA 的 bilinear reproject + 多帧混合 + clip → 天然有软化。工业实践在 TAA 输出后接一个轻量 sharpen（unsharp mask 或 CAS-lite）：subtract 一点低通版本 + 加回高频。UE 里叫 "TAA sharpen"，DLSS 里内置。

左：raw TAA 输出（模糊）；右：sharpen 之后。使用 5-tap 减 4 邻域拉伸公式：C' = C·(1+4s) − s·(N+S+E+W)。

unsharp mask
low = blur(image, 1px) high = image − low out = image + amount · high = (1 + amount) · image − amount · low
CAS (Contrast Adaptive Sharpening)：AMD 的锐化算法，根据局部对比度调整锐化幅度——平坦区不锐化避免 amplify noise，边缘区多锐化。DLSS/FSR2 都用类似思路。
08 · DLSS / FSR / TSR

和 TAA 什么关系？

DLSS / FSR2 / TSR / XeSS 本质都是 temporal upscaler：从低分辨率 render + jitter + motion vector + history，还原到高分辨率。核心还是 TAA 那套（jitter + reproject + clip），但加了：（1）低分辨率 render；（2）神经网络 or heuristic 更聪明的 accumulation；（3）超分辨率注意力。理解了 TAA 就理解了这些技术 80%。

概念对比：TAA 保原分辨率；DLSS/FSR 输入 1/2 或 1/3 分辨率，通过多帧累积拼回原分辨率。同样 4~8 帧融合 = 有效样本数追平原分辨率，但 rasterize + shading 成本减半。

三家对比

  • DLSS (NVIDIA)：Tensor Core 上跑 CNN 决定权重和 history clip 策略。质量最高，仅 RTX 卡。
  • FSR2/3 (AMD)：纯 heuristic，开源，跨平台。质量略逊 DLSS 但通吃所有 GPU。
  • TSR (UE5)：Epic 自研，heuristic 为主 + 可选 ML 加速，深度融入 Nanite / Lumen 管线。
  • XeSS (Intel)：Arc GPU 有 XMX 加速 CNN，其他 GPU 走 fallback。
